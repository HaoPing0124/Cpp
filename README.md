## STL 容器模拟实现

### Vector

主要练习内容：

- 动态数组管理
- 容量与元素数量管理
- 扩容策略
- `push_back`
- `pop_back`
- `operator[]`
- 拷贝构造
- 赋值运算符重载
- 析构和资源释放

Vector 的核心目标是理解：

```text
连续内存
   │
   ├── size：当前元素数量
   └── capacity：当前可用容量
```

当容量不足时：

```text
申请更大的新空间
       │
       ▼
复制或移动原有元素
       │
       ▼
释放旧空间
       │
       ▼
更新内部指针
```

### List

- 头插和尾插
- 指定位置插入
- 指定位置删除
- 简单迭代器实现
- 链表边界处理

链表结点关系：

```text
prev <── Node ──> next
```

### String

主要练习内容：

- 深拷贝
- 字符串拼接
- 下标访问
- 查找和比较
- 运算符重载
- 资源释放

### Priority Queue

主要练习内容：

- 大根堆
- 小根堆
- 向上调整
- 向下调整
- 插入元素
- 删除堆顶元素
- 自定义比较规则

堆的数组下标关系：

```text
父结点下标：    (child - 1) / 2
左孩子下标：    parent * 2 + 1
右孩子下标：    parent * 2 + 2
```

## 编译运行

仓库中的大多数 `.cpp` 文件可以独立编译。

使用 G++：

```bash
g++ -std=c++17 source.cpp -o app
./app
```

例如：

```bash
g++ -std=c++17 test.cpp -o test
./test
```

在 Windows PowerShell 中运行：

```powershell
g++ -std=c++17 source.cpp -o app.exe
.\app.exe
```

使用 Visual Studio 时，可以打开对应目录中的解决方案或源文件进行编译运行。
