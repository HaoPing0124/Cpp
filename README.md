## STL 容器模拟实现

### Vector

`vector/` 目录用于模拟实现 `std::vector` 的核心功能。

主要练习内容：

- 连续内存管理
- 元素数量与容量管理
- 动态扩容
- `push_back`
- `pop_back`
- `insert`
- `erase`
- `operator[]`
- 拷贝构造
- 赋值运算符重载
- 析构与资源释放

Vector 的核心结构可以理解为：

```text
_start        指向有效数据的起始位置
_finish       指向最后一个有效元素的下一个位置
_end_storage  指向已申请空间的末尾
```

当容量不足时，需要完成以下操作：

```text
申请更大的新空间
        │
        ▼
复制或移动原有元素
        │
        ▼
释放旧空间
        │
        ▼
更新内部指针
```

### 二叉搜索树

`BinarySearch/` 目录主要用于实现二叉搜索树。

二叉搜索树通常满足：

```text
左子树结点值 < 当前结点值 < 右子树结点值
```

主要实现内容：

- 结点结构设计
- 插入结点
- 查找结点
- 删除结点
- 中序遍历
- 模板类封装
- 不同删除情况的处理

删除结点时通常需要考虑：

```text
没有孩子结点
只有左孩子
只有右孩子
同时存在左右孩子
```

## 编译运行

仓库中的大多数 `.cpp` 文件可以独立编译运行。

### Linux 或 macOS

使用 G++ 编译：

```bash
g++ -std=c++17 source.cpp -o app
```

运行：

```bash
./app
```

完整示例：

```bash
g++ -std=c++17 test.cpp -o test
./test
```

### Windows PowerShell

编译：

```powershell
g++ -std=c++17 source.cpp -o app.exe
```

运行：

```powershell
.\app.exe
```

### Visual Studio

使用 Visual Studio 时，可以：

1. 打开对应目录中的解决方案文件；
2. 将需要运行的 `.cpp` 文件添加到项目；
3. 设置启动项目；
4. 编译并运行程序。

> 部分目录可能包含多个独立的 `main` 函数，编译时应只选择当前需要运行的源文件。
